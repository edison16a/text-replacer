# Data files

Everything the extension used to hard-code. These are read at runtime, so
changing any of them is a data edit, not a code change. Run `npm run validate`
afterwards.

These files hold data and nothing else. There are no comment keys in them,
because a consumer that reads a file by key cannot tell a note from a real
entry, and every reader would have to remember to skip it.

## `selectors.json`

Which elements get replaced.

`text` is the list of elements whose text is overwritten. Each entry is one CSS
selector on its own; they are joined with a comma at runtime. Add `"caption"`
and figure captions start being replaced too.

`image` is the same thing for images. It is a list for symmetry, and there is
one entry in it.

## `config.json`

`replacementIntervalMs` is how often every open tab is rewritten, in
milliseconds. The extension has always used one second.

## `strings.json`

Every visible word in the popup, as a flat map of key to copy. The markup holds
no words of its own: it marks its slots with `data-string`,
`data-string-placeholder` and `data-string-alt` attributes naming a key here.

A slot naming a key that does not exist throws on load rather than rendering an
empty element, because a blank button is much harder to notice than a stack
trace.

## `theme.json`

Every colour in the popup, in two layers.

`palette` defines each distinct colour once. `roles` says which part of the UI
uses which palette entry. The stylesheet refers to roles as
`var(--color-<role>)`, and the popup turns them into custom properties on
`:root` when it loads.

Change a palette value to recolour everything that uses it. Point a role at a
different palette entry to change one thing.

## Where these values came from

`strings.json` and `theme.json` were generated by `tools/extract-strings.mjs`
and `tools/extract-theme.mjs`, which read the pre-refactor source at a pinned
revision so none of it was retyped. Those are one-off migration scripts kept
for provenance. You do not need to run them to change anything, and these files
are the source of truth now.
